# Crypto AI Telegram Bot — Railway Ready

## Required
- TELEGRAM_BOT_TOKEN
- ADMIN_TELEGRAM_IDS
- GROQ_API_KEY

## Optional
- COINGECKO_API_KEY
- BINANCE_API_KEY
- BINANCE_API_SECRET

## Railway
1. Upload/push these files to GitHub.
2. Railway -> New Project -> Deploy from GitHub Repo.
3. Add the required variables in Railway Variables.
4. Start command: `python bot.py`.
5. Deploy and check logs.

CryptoPanic is NOT required. `/news` uses public RSS feeds.
